Milestone 3 · stated before the next code change

Hypothesis

We train XCCNet on all 5,856 Kermany films. The split is stratified 80/10/10. The run uses CLAHE and a lung mask. CLIP stays frozen. This run does not include the GAN. This run does not include rib suppression.

ResultAccPrecRecallF1
Our test, 585 films94.87%94.81%98.36%96.55%
Paper, traditional aug97.18%94.52%98.65%96.54%
Paper, full stack99.76%99.75%99.75%99.75%

The model misses 7 pneumonia films and marks 23 normal films as pneumonia. The 99.76% test adds 2,624 synthetic normal films, so the two classes are almost equal.

Hypothesis. The gap comes from the GAN and from rib suppression. Prediction. Add one of those two stages on this same split. Accuracy on the 585-film test rises above 94.87%. The same model on the official 624-patient test scores below 94.87%.
